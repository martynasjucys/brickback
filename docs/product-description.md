# BrickBack

> **Bring LEGO® sets back from a pile of bricks.**

## Overview

BrickBack is a mobile app designed to help LEGO enthusiasts rebuild complete sets from mixed or second-hand collections.

Instead of manually comparing every part against printed instructions, BrickBack presents an interactive inventory where users simply count the parts they have. The app tracks progress, highlights missing pieces, verifies completion, and generates everything needed to confidently rebuild or sell the set.

Whether you've bought a bulk lot at a flea market, inherited a collection, or are sorting your own bricks, BrickBack turns a tedious inventory process into a fast, structured workflow.

---

# Core Workflow

1. **Select a LEGO set**

    * Search by set number or name.
    * Scan the instruction booklet or box (future).
    * Open directly from a shared link.

2. **Collect the inventory**

    * Browse the inventory grouped into manageable sections.
    * Tap parts to increase the collected count.
    * Track progress in real time.
    * Pause and continue anytime.

3. **Review results**

    * View completion percentage.
    * See exactly which parts are missing.
    * Verify minifigures separately.
    * Export missing parts for purchasing.

4. **Finish**

    * Mark the set as verified.
    * Generate an Inventory Verification report.
    * Share or print the verification certificate.

# Core Features

## Inventory Collection

* Interactive inventory grid
* Fast tap-to-count workflow
* Progress tracking
* Missing part detection
* Part images for quick identification
* Minifigure verification

---

## Inventory Verification

After completing the inventory, BrickBack generates a verification summary containing:

* Set information
* Completion status
* Parts found
* Missing parts
* Minifigure status
* Verification date
* Optional notes
* Seller-friendly verification card

The verification can be shared as an image or exported as a printable PDF.

---

## Missing Parts Export

When parts are missing, users can export the missing inventory to marketplaces such as BrickLink for quick purchasing.

# Design Principles

BrickBack should feel:

* Fast
* Clean
* Trustworthy
* Focused
* Mobile-first

The interface should disappear into the background, allowing users to stay focused on sorting bricks rather than navigating menus.

---

# Philosophy

BrickBack is **not** a LEGO collection manager, marketplace, or price tracker.

Its single purpose is to help people **bring LEGO sets back together**.

Everything in the app should support that mission:

* identify the set
* collect the inventory
* verify completion
* rebuild with confidence

Nothing more, nothing less.
